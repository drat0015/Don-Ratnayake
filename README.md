# FIT2179 Data Visualisation 2

## Australia’s Cost of Living Crisis

### Dashboard Overview

This interactive data visualisation dashboard explores the growing cost-of-living crisis across Australia. The project investigates how rising inflation, housing costs, food prices and transport expenses are affecting households in different Australian states and territories.

The dashboard combines multiple Vega-Lite visualisations to communicate economic pressure trends, household spending patterns and affordability challenges through a responsive and story-driven layout.

## Features

- Interactive choropleth map of Australian state pressure levels
- CPI inflation trend analysis
- Inflation by spending category
- Food price growth comparison
- State cost pressure ranking
- Household pressure heatmap
- Household spending share visualisation
- Rent vs wage growth comparison
- Household budget donut chart
- Key insight summary cards

## Design Approach

The dashboard was designed using a narrative storytelling approach. Visualisations are arranged in sections that progressively explain the economic pressures affecting Australian households. The design focuses on readability, responsive layout, consistent visual styling and effective communication of insights.

The dashboard sketch and layout planning were developed before implementation to ensure a structured storytelling flow.
